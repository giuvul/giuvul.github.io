DataOps

The platform
beneath the pipeline

A pipeline should prove what is running, not assume it. Every deployment system has a state where the automation reports success and the old code is still serving traffic — and if nothing compares the two, nobody finds out from a dashboard.

System
Passenger profiling platform
Scale
Two environments, one declared source
Role
Sole architect and engineer
Stack
Terraform / AWS ECS / GitHub Actions
01

The challenge

A release passed every check and was then silently reverted by the platform's own safety mechanism. Nothing in the pipeline was built to notice.

02

The approach

Declare the whole platform as code, make the quality gates ratchet, and end every deployment by proving what is running.

03

The result

An entire class of green-pipeline failures became impossible to miss, and the data platform can be rebuilt from source rather than from memory.
